# blog-notes

这里整理了一组面向学习、复习和博客发布的 Java 知识笔记。

内容以 Markdown 文章为主，配图统一放在各目录的 `imgs/` 文件夹中。文章按照编号排序，方便按顺序阅读，也方便后续同步到博客平台。

## 内容目录

### Java 基础

`Java 基础` 目录是 Java 入门到基础进阶的系列文章，适合按顺序阅读：

- Java 开发环境搭建
- Java 运行机制与程序结构
- 数据类型与运算符
- 流程控制与数组
- 面向对象基础：类与对象
- 封装、继承、多态
- 抽象类与接口
- Java 内存布局与垃圾回收

### 杂项知识点

`杂项知识点` 目录用于整理 Java 学习中容易混淆、但又很重要的独立知识点：

- 宽化基本类型转换
- 复合赋值与类型提升
- 浮点数精度
- String 常量池、`==`、`equals`
- String 为什么不可变
- 自动装箱、自动拆箱与 IntegerCache
- Java 整数除法、取模和负数取模
- Java 参数传递
- final 关键字
- equals 与 hashCode

## 说明

这些文章主要服务三个目标：

1. 把零散知识整理成可以长期复习的 Markdown 笔记。
2. 用图示、示例和对比表降低 Java 基础概念的理解成本。
3. 保持适合发布到博客平台的文章结构，方便后续同步和维护。

## 适合谁阅读

- 正在入门 Java 的学习者
- 想系统复习 Java 基础语法的人
- 准备面试，需要补齐基础概念的人
- 希望理解 Java 常见易错点的人
